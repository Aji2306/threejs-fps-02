BREACHLINE — an original tactical FPS built with Three.js for the make.fun competition. A 5v5 tactical rounds-based shooter set in "Foundry Yard", an industrial foundry yard at dusk with orange and teal palettes. Two bomb sites (Site A "Furnace" and Site B "Crane Yard"), economy management, buy menu, precise hitscan gunplay with spread/recoil, bots with waypoint graphs and roles, and synthesized WebAudio sound effects.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in Chrome.
