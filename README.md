# Breachline

An original tactical FPS built with Three.js for the make.fun competition.

## Overview
"Breachline" is a 5v5 tactical rounds-based shooter set in "Foundry Yard", an industrial foundry yard at dusk with orange and teal palettes. Two bomb sites (Site A "Furnace" and Site B "Crane Yard"), economy management, buy menu, precise hitscan gunplay with spread/recoil, bots with waypoint graphs and roles, and synthesized WebAudio sound effects.

## How to Run
1. Install dependencies or run static server:
   ```bash
   node serve.ts
   ```
2. Open `http://localhost:8080` in Chrome.
